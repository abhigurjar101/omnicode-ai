# Publication scope

This repository contains the working application source from Abhi Kumar Gurjar's local `omnicode-ai` project: core engine, FastAPI service, CLI, Next.js workspace, tests, documentation, example solutions and alternate UI experiments.

NEMI-CODE, NEMICODE and OMNICODE identifiers coexist in the original implementation. They are retained where imports, routes, test expectations and compatibility settings depend on them. The repository is published as OmniCode AI; it is distinct from the separate NEMI GraphRAG repository.

Credentials, local environment files, memory/learning databases, build caches, installed dependencies, deployment-account metadata, screenshots, recordings, temporary captures and accidental non-source files are excluded. A blank environment template is included. Existing framework, decoder and asset credits are retained; no new third-party license grant or independent competitor benchmark is asserted.
